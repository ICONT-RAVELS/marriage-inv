# Wedding Invitation Website

Static site (single `index.html`) - no build step needed.

## Publish on GitHub Pages
1. Create a new repository on GitHub (e.g. `wedding-invite`).
2. Upload all files from this folder (index.html, .nojekyll, README.md).
3. Go to Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / root > Save.
4. Your site will be live at https://YOUR-USERNAME.github.io/wedding-invite/

## Customize
Open `index.html` and replace the `XXXX` placeholders with names, dates and venue.
WhatsApp/call number: search for `917871134250`.
